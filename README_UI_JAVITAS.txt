Növényfigyelő UI javítás

Változások:
1. Bejelentkezésnél a jelszó mező kapott szem ikont.
2. Fiók hozzáadásánál a jelszó mező kapott szem ikont.
3. Az email értesítés mentése után már nem a böngésző alap alert ablaka jelenik meg.
4. Helyette az oldal stílusához illő, zöld-fehér modern visszajelző jelenik meg.
5. Netlify feltöltésnél figyeltem arra, hogy ne maradjon # vagy ? karakteres fájlnév.

Feltöltés:
- A ZIP tartalmát töltsd fel GitHubra / Netlifyra.
- Fontos: ne csak az index.html-t töltsd fel, mert a változás érinti a styles.css és notifications.js fájlt is.
